#  Games Hub Backend Launcher - Python

A command-line game launcher built in Python to practice backend logic, flow control, and data validation.

###  Included Games
* **Heads or Tails (1):** Luck-based game featuring strict string sanitization and inputs.
* **Hangman Game (2):** Turn-based vocabulary game running with dual loop structures, life reduction trackers, and real-time word arrays modification.
* **Guess the Number (3):** Mathematical game with turn tracking, numeric boundaries (`range`), and higher/lower hints.
* **Slot Machine (4):** Casino simulator with dynamic balance updates, customized betting, and a 20x Jackpot payout.


###  Practices & Technologies Applied
* Flow control with nested `while` loops.
* Input validation and data sanitization using `.strip().lower()`.
* List mapping, tuples usage, and probability mechanics.
* Main menu loop interruption handled via `break`.

###  Project Purpose
This repository was developed exclusively for learning and educational purposes. It serves to practice structural programming concepts, logic building, and terminal control syntax in Python.
